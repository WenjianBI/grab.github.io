# README

This repository contains the source for the [GRAB manual page](https://wenjianbi.github.io/grab.github.io/).

**GRAB** is an R package offering a comprehensive suite of GWAS methods designed for biobank-scale datasets. The GitHub repository is at [https://github.com/GeneticAnalysisinBiobanks/GRAB](https://github.com/GeneticAnalysisinBiobanks/GRAB), and the CRAN page is available at [https://CRAN.R-project.org/package=GRAB](https://CRAN.R-project.org/package=GRAB).
