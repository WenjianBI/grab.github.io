# Setup Files

This folder contains setup instructions and helper files that are not part of the GRAB package documentation.

These files are excluded from Jekyll processing (see `_config.yml`) and will not appear on the documentation website.

## Files

- **SETUP_COMPLETE.md** - Complete setup guide for the documentation site
- **DEPLOYMENT_SUMMARY.md** - Summary of deployment improvements
- **THEME_UPDATE_SUMMARY.md** - Details about the theme update to Cayman

## Note

These files are kept for reference but are not published to the live documentation site at https://wenjianbi.github.io/grab.github.io/
